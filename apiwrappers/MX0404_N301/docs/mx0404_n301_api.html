Command Reference

Switch / Get

  • Command: GET MP
  • Syntax: GET MP <output|all>
  • Description: Get the input mapping for one output or all outputs
  • Parameters: output
  • Response Type: string

mapping: string

Switch / Set

  • Command: SET SW
  • Syntax: SET SW <input> <output|all>
  • Description: Route one input to one output or to all outputs
  • Parameters: input, output
  • Response Type: confirmation

input: string
output: string

Audio Mute / Get

  • Command: GET AUDIO_MUTE
  • Syntax: GET AUDIO_MUTE <zone>
  • Description: Get the mute state for an analog audio zone
  • Parameters: zone
  • Response Type: string

zone: string
state: string

Audio Mute / Set

  • Command: SET AUDIO_MUTE
  • Syntax: SET AUDIO_MUTE <zone> <on|off>
  • Description: Mute or unmute an analog audio zone
  • Parameters: zone, state
  • Response Type: confirmation

zone: string
state: string
