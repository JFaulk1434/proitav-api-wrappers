Command Reference

Switch / Get

  • Command: GET MP
  • Syntax: GET MP <hdmiout1..hdmiout8|all>
  • Description: Get the current HDMI input mapping for one output or all outputs.
  • Parameters: output
  • Response Type: string

mapping: string

Switch / Set

  • Command: SET SW
  • Syntax: SET SW <hdmiin1..hdmiin8|hdmiin0> <hdmiout1..hdmiout8|all>
  • Description: Route one HDMI input to one HDMI output or to all outputs. hdmiin0 powers down the selected output path.
  • Parameters: input, output
  • Response Type: confirmation

input: string
output: string

Audio Switch / Get

  • Command: GET AUDIOMP
  • Syntax: GET AUDIOMP <audioout1..audioout8>
  • Description: Get the current audio source mapped to one analog audio output.
  • Parameters: output
  • Response Type: string

source: string
output: string

Audio Switch / Set

  • Command: SET AUDIOSW
  • Syntax: SET AUDIOSW <hdmi|arc> <audioout1..audioout8>
  • Description: Select whether an analog audio output follows HDMI audio extraction or ARC audio.
  • Parameters: source, output
  • Response Type: confirmation

source: string
output: string

Cec Power

  • Command: SET CEC_PWR
  • Syntax: SET CEC_PWR <hdmiout1..hdmiout8|all> <on|off>
  • Description: Send a CEC power command to one sink or all sinks.
  • Parameters: output, state
  • Response Type: confirmation

output: string
state: string

  • Syntax: SET AUTOCEC_FN <hdmiout1..hdmiout8> <on|off>

Cec Delay / Get

  • Command: GET AUTOCEC_D
  • Syntax: GET AUTOCEC_D <hdmiout1..hdmiout8>
  • Description: Get the automatic CEC power-off delay for one output.
  • Parameters: output
  • Response Type: string

output: string
minutes: integer

Cec Delay / Set

  • Command: SET AUTOCEC_D
  • Syntax: SET AUTOCEC_D <hdmiout1..hdmiout8> <0..30>
  • Description: Set the automatic CEC power-off delay in minutes for one output.
  • Parameters: output, minutes
  • Response Type: confirmation

output: string
minutes: integer

Cec Command / Get

  • Command: GET CECCMD_EDIT
  • Syntax: GET CECCMD_EDIT <hdmiout1..hdmiout8> <pwron|pwroff>
  • Description: Read the stored custom CEC power-on or power-off command for one output.
  • Parameters: output, command_type
  • Response Type: string

output: string
command_type: string
hex_bytes: string

Cec Command / Set

  • Command: SET CECCMD_EDIT
  • Syntax: SET CECCMD_EDIT <hdmiout1..hdmiout8> <pwron|pwroff> <hex_bytes>
  • Description: Store a custom CEC power-on or power-off command for one output.
  • Parameters: output, command_type, hex_bytes
  • Response Type: confirmation

output: string

hex_bytes: string

Edid / Get

  • Command: GET EDID
  • Syntax: GET EDID <hdmiin1..hdmiin8|all>
  • Description: Get the EDID preset assigned to one input or all inputs.
  • Parameters: input
  • Response Type: string

edid: string

Edid / Set

  • Command: SET EDID
  • Syntax: SET EDID <hdmiin1..hdmiin8> <1..27>
  • Description: Assign one of the vendor EDID presets to an HDMI input.
  • Parameters: input, profile
  • Response Type: confirmation

input: string
profile: integer

Edid Write

  • Command: SET EDID_W
  • Syntax: SET EDID_W <hdmiin1..hdmiin8> <block0|block1> <hex_bytes>
  • Description: Write one EDID block to an HDMI input. The device returns ok or error for checksum validation.
  • Parameters: input, block, hex_bytes
  • Response Type: confirmation

input: string
block: string
status: string

Edid Read

  • Command: GET EDID_R
  • Syntax: GET EDID_R <hdmiout1..hdmiout8>
  • Description: Read EDID block data from one HDMI output. The device can return block data, error, or unconnect.
  • Parameters: output
  • Response Type: string

output: string
block0: string
block1: string
status: string
